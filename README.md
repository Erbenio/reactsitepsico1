<h2> Sobre o Projeto</h2>

<p>
Este projeto consiste em um website institucional desenvolvido em React com foco na apresentação de serviços psicológicos e aplicação prática dos conceitos estudados na disciplina de Desenvolvimento Web III.
</p>

<p>
O sistema foi construído utilizando componentização, Props, renderização dinâmica, CSS Modules, responsividade e reutilização de componentes.
</p>

---

<h2> Objetivos do Projeto</h2>

<ul>
  <li>Desenvolver uma aplicação React baseada em componentes reutilizáveis</li>
  <li>Aplicar conceitos de JSX e Props</li>
  <li>Trabalhar renderização dinâmica com map()</li>
  <li>Implementar CSS Modules</li>
  <li>Criar layout moderno e responsivo</li>
  <li>Simular um website profissional da área de psicologia</li>
</ul>
